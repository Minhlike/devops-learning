- **Vị trí mục tiêu:** DevOps Intern/Fresher, Cloud Operations Fresher, Linux Sysadmin Intern

## Đánh giá Nền tảng Thực tế (Kết quả Diagnostic Test)
- **Trình độ hiện tại:** Người bắt đầu từ số 0 ở mảng Linux & System Ops, có tư duy logic lập trình sơ cấp.
- **Điểm mạnh:**
  1. Tư duy logic lập trình tốt (Đọc hiểu code Python, biến, hàm, vòng lặp chuẩn xác 100%).
  2. Khái niệm biến môi trường (Environment Variable) và tính bảo mật nắm khá tốt.
  3. Tiếng Anh đọc hiểu tài liệu kỹ thuật tốt.
  4. Thái độ học tập trung thực, không lạm dụng AI/Google khi kiểm tra.
- **Điểm yếu:**
  1. Kỹ năng Terminal / CLI Linux gần như bằng 0.
  2. Mạng máy tính hổng các khái niệm thực hành: Port, Subnet, Gateway, TCP/UDP, HTTP status code.
  3. Chưa có kỹ năng đọc log lỗi (Error log/Stack trace) và chưa hiểu luồng Request.
  4. Chưa nắm khái niệm HĐH chuyên sâu (Process, Service, Path, Swap, Executable binary).
- **Rủi ro:** Dễ bị ngợp ở giai đoạn chuyển từ giao diện GUI sang thao tác thuần bàn phím trên CLI Linux nếu không luyện tập phản xạ hàng ngày.

- **Mục tiêu 9 tháng (Hết Phase 11-12):** Hoàn thành Kubernetes, Helm, Observability, DevSecOps và Capstone 3. Đạt mức **Competitive Junior Candidate**.
