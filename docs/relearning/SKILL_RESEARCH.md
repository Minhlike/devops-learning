# Thẩm định nguồn skill bên ngoài

Đã đọc trang repository ngày 2026-11-01: https://github.com/iannbing/skills-for-learning ; https://github.com/Solizardking/skills ; https://github.com/anthropics/skills . Đây mới là nghiên cứu tài liệu công khai, chưa kiểm source implementation từng skill. Không cài đặt, thực thi hoặc sao chép mã bên thứ ba.

Áp dụng thiết kế riêng: scaffolding qua worked example ở guided; giảm hỗ trợ ở independent; retrieval bằng giải thích lại cơ chế; feedback theo output; spaced review đơn giản +7/+21 hoặc +2 khi lặp lỗi; checkpoint nhỏ để giảm context. Không coi README quảng cáo là chứng cứ hiệu quả giáo dục hoặc chức năng phần mềm đã chạy. Muốn tích hợp skill cụ thể cần khóa commit, kiểm SKILL.md và code, license từng file, quyền dữ liệu và negative tests. Không có dependency runtime với framework Agent bên ngoài.
