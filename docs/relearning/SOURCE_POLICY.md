# Nguồn và phiên bản

Mỗi lesson catalog có URL chính thức, section, version scope và mục đích. Với bài DESIGNED, docs là điểm vào nghiên cứu, chưa là claim đã xác minh từng dịch vụ/API. Khi AUTHORED phải bổ sung mục chính xác cho mọi lệnh/đặc tính được dùng; khi VERIFIED phải ghi môi trường và output thật. Không suy current URL luôn cùng version.

Ngày tra: 2026-11-01. Java 17 LTS hiện có trên máy; Spring Boot 4.1.2 theo system requirements chính thức hỗ trợ Java 17, Maven >=3.6.3. Chọn Maven 3.9.x khi cấp môi trường, Python 3.12 stdlib, Go module target 1.26, PostgreSQL 18 cho thiết kế. Chưa kiểm Maven build hoặc PostgreSQL runtime cục bộ.

Nguồn đã đọc trực tiếp: https://docs.spring.io/spring-boot/system-requirements.html ; https://spring.io/projects/spring-boot/ ; https://www.oracle.com/java/technologies/java-se-support-roadmap.html ; https://docs.docker.com/engine/containers/run/ ; https://docs.docker.com/engine/storage/drivers/ ; https://go.dev/doc/go1.26 ; https://www.postgresql.org/docs/18/sql-select.html . Trang web rolling phải kiểm lại trước buổi học.

Chứng chỉ: catalog cố ý NOT_MAPPED. Không tuyên bố sẵn sàng thi. Muốn map phải lưu exam blueprint chính thức, ngày kiểm, phiên bản và objective → lesson/lab/evidence cụ thể.
